# Violet's Storybook

Violet's Storybook 是一个面向个人故事收藏的本地优先网页应用原型。当前交付为 **可部署到 GitHub Pages 的静态网页源码**，不是已编译的 Android APK。

## 快速开始

1. 解压源码 ZIP。
2. 推荐通过本地静态服务器或 HTTPS 打开，而不是直接双击 `index.html`。例如在项目目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。
3. 数据保存在当前浏览器、当前网站来源的 IndexedDB 中。它不会自动同步到 GitHub，也不会自动在不同设备或浏览器间同步。
4. 定期在「设置与备份」中导出 ZIP，并将备份保存在项目文件夹之外。

## 已实现的核心功能

### 番外、角色与系列
- 导入或粘贴 HTML、Markdown、TXT；标题必填且可编辑。
- 编辑正文、简介、角色关联、系列、标签与封面。
- 阅读器支持常见 Markdown，包括标题、强调、列表、引用、代码块和表格；可查看原始内容。
- 普通文本和 Markdown/HTML 源码编辑模式；支持草稿、撤销/重做和上一正式版本恢复。
- 封面卡片与纯文字卡片切换；系列内番外可拖动排序并更新章节顺序。
- 角色和系列可新建、编辑、删除；删除系列会把故事移至未分类，不删除正文。
- 阅读进度会随阅读滚动保存。

### 音乐与配乐
- 支持导入本地音频或添加可直接播放的 HTTP(S) 音频直链。
- 本地音频、封面二进制保存到 IndexedDB；同一首曲目可被多个歌单引用。
- 歌单支持增删曲目和独立排序。固定曲目列表与动态歌单是不同模式。
- 配乐按单篇番外、系列、选择的关联角色、全局设置的层级解析；可选择继承、自定义或关闭。
- 支持继承/指定循环规则、自动播放规则、播放进度与基本播放控制。
- 浏览器的自动播放策略可能要求用户手动点按播放；网页后台/锁屏音频能力取决于浏览器和系统。

### 主题与样式
- 管理应用主题、阅读主题和组合主题；可设置全局主题、系列主题和单篇覆盖。
- 编辑、导入、导出 CSS；提供基础语法检查、预览、查找替换、撤销/重做和草稿。
- 阅读主题 CSS 会限制在阅读器范围内，并过滤部分高风险声明。它不是完整的 CSS 隔离沙箱，不建议把来源不可信的任意 CSS 用于公开服务。

### 保存与备份
- 故事元数据、设置、歌单和主题保存在 IndexedDB。
- ZIP 备份包括 `backup.json`、封面和（按设置选择的）本地音频；恢复前会检查归档目录、大小和 CRC。解压后总大小上限为 300 MiB，导入 ZIP 文件本身上限为 330 MiB，单包超限时请排除音频或分批处理。
- JSON 备份只包含结构化数据，不含封面/音频二进制。若 ZIP 排除音频，恢复后的相关曲目会标记为需重新导入。
- 还可以单独导出番外文本/Markdown/HTML 或主题 CSS。

## 部署到 GitHub Pages

1. 在 GitHub 创建一个空仓库。
2. 把解压后 `violets-storybook` 文件夹**里面**的全部内容上传到仓库根目录；确认 `index.html` 位于仓库根目录，而不是下一层子文件夹。
3. 进入仓库 **Settings → Pages**。
4. 在 Build and deployment 中选择 **Deploy from a branch**，选择 `main` 分支和 `/(root)`，保存。
5. 等待 GitHub Pages 部署完成后，打开 Pages 页面给出的 HTTPS 地址。
6. 先用测试故事、测试音频做一次导入、刷新、ZIP 导出和恢复，再导入正式收藏。

每个 GitHub Pages URL 都是独立的浏览器存储来源。不要把个人故事、音频或备份提交进公开 Git 仓库；本应用的收藏数据应留在浏览器数据库和你单独保存的备份里。

## 重要限制与安全说明

- 本项目是静态网页原型，不是 APK；尚未编译或在 Android 实机上验证。不能据此承诺后台/锁屏播放、系统媒体通知或 Android 文件权限。
- IndexedDB 受浏览器配额、用户清理浏览数据、隐私模式和设备存储空间影响。完整 ZIP 备份仍然很重要。
- 本地媒体可以在同一个网站来源下跨页面刷新保存；重新部署同一个来源通常保留浏览器数据，但清理站点数据、切换域名或切换浏览器不会自动迁移数据。
- 网页端仅实现保守的 HTML/CSS 过滤，不应把它视作专用安全沙箱。不要依赖它安全执行不可信脚本或样式。
- 浏览器不保证未经用户交互的自动播放成功；网络音频必须是浏览器可直接访问的媒体直链，平台页面链接通常不能直接播放。

## 文件结构

- `index.html`：页面结构与对话框。
- `styles.css`：米白、海军蓝、金色与淡薰衣草紫的样式。
- `app.js`：数据模型、导入阅读、媒体持久化、歌单、主题和备份恢复。
- `service-worker.js`：静态资源离线缓存。
- `manifest.webmanifest`：PWA 元数据。
- `assets/`：应用图标和签名字体。
- `REQUIREMENTS.md`：产品需求与范围记录。
- `AUDIT_NOTES.md` / `TEST_REPORT.md`：当前实现范围和验证结果。
